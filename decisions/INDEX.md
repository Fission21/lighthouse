# ADR 索引

> 灯塔的架构决策记录。人类用 `Ctrl+F`，AI 用 `grep`。
> 决策写在 [`adr/`](adr/) 里，本文件只做导航与状态汇总。

## 维护约定

1. 新增：复制 [`_template.md`](_template.md) 到 `decisions/adr/YYYY-MM/YYYY-MM-DD-NNNN-short-title.md`，编号全局递增、不复用。
2. 写完同时更新本文件的**按编号**、**按状态汇总**、**按标签**三处；状态变化也要同步。
3. 已采纳的 ADR **不改原始结论**；实质取代时写新 ADR，并把旧的标为「已废弃（被 NNNN 取代）」。
4. 普通实现选择、一次性踩坑不立 ADR —— 前者写进代码注释与文档，后者进 [`docs/ISSUES.md`](../docs/ISSUES.md)。
5. `tests/check_docs.py` 会核对编号连续、文件与索引双向一致、每篇都有状态行。

# ADR 模板

复制本文件到 `decisions/adr/YYYY-MM/YYYY-MM-DD-NNNN-short-title.md`：

- 编号 `NNNN` **全局递增、不复用**（新增前看 `decisions/INDEX.md` 的最大编号）。
- 日期、编号、英文短标题缺一不可；标题里的词用短横线连接。
- 写完同步 `decisions/INDEX.md` 的按编号表、按状态汇总、按标签三处。
